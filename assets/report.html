General run statistics
Read yield evolution
This section provides an overview of the sequencing run, including the number of reads generated, total bases sequenced, and other key metrics.
The Sankey plot shows the flow of sequenced reads through consensus generation. It displays reads that pass or fail consenus. Reads that pass consensus are further categorized by their type (1D, 2D or 3D). Reads that fail consensus are further categorized by their reason for failure.
This section shows the yield of consensus read bases generated.
The Sankey plot shows the proportion of consensus bases by read type (1D, 2D, 3D) after successful consensus. When consensus fails, the underlying reason is displayed.
This section shows the yield of raw read bases analysed.
The Sankey plot shows the proportion of raw bases by read type (1D, 2D, 3D) after successful consensus. When consensus fails, the underlying reason is displayed.
Depth per amplicon
This section shows the median depth of coverage for each amplicon. For each amplicon, read depth is determined at each position, and the median depth across the locus is calculated.
If a target depth is specified, it is shown as a dashed line. Amplicons that meet the target are colored blue.
Detected variants
This section lists the variants detected in the sample. Variants are identified by comparing the consensus sequences to the reference genome. The table includes information about each variant, such as its genomic position, codon and amino acid changes, type (e.g., SNV, indel), and allele frequency.
Use the buttons above the table to select which variants to display.

Read structures
This histogram shows the distribution of consensus read lengths stratified by read type.
This histogram shows the distribution of raw read lengths stratified by read type.
This histogram shows the number of repeats in each processed read. A repeat is defined as the base subunit of a concatemeric read, typically corresponding to the original insert.
The distribution of the number of repeats is stratified by read type.
This section shows the fraction of mapped bases per read. That is, for each read, the number of bases that successfully mapped to the reference, over the total read length.
The distribution of mapped fractions is stratified by read type.
